1. Общие положения

Эта Политика объясняет, какие персональные данные обрабатывает сайт https://keis-legalgroup.ru, зачем они нужны, как они защищаются и какие права есть у пользователя. Использование сайта означает согласие с условиями Политики.

2. Цели обработки персональных данных

Администрация Сайта обрабатывает персональные данные Пользователей для следующих целей:

  • Корректная работа сайта и его форм;
  • Предоставление Пользователям информации об услугах, актуальных предложениях, акциях и новостях, связанных с деятельностью Сайта;
  • Связь с пользователем по обращениям, отправленным через сайт;
  • Улучшение качества обслуживания и оптимизация интерфейса и контента Сайта на основе анализа активности Пользователей.

3. Состав обрабатываемых персональных данных

В рамках использования Сайта могут обрабатываться следующие персональные данные Пользователей:

  • Имя, фамилия и контактная информация (телефон, адрес электронной почты);
  • Данные, указанные при регистрации на Сайте или при отправке запросов через формы обратной связи;
  • Технические данные о посещении сайта: IP-адрес, браузер, устройство, просмотренные страницы и переходы по ссылкам;
  • Файлы cookie, используемые для упрощения использования Сайта и повышения удобства Пользователей.

4. Методы сбора персональных данных

Персональные данные могут собираться следующими методами:

  • Путем предоставления информации напрямую Пользователем (при заполнении форм на Сайте или обращении в поддержку);
  • С использованием автоматических технологий сбора данных (cookie, аналитические сервисы, сбор данных о сессиях);
  • Посредством обработки обращений, отзывов и запросов Пользователей, направляемых через формы обратной связи.

5. Хранение и защита персональных данных

Администрация сайта принимает меры, чтобы персональные данные не получили посторонние лица и чтобы данные не были изменены или удалены без оснований. Данные хранятся на защищенных серверах с ограниченным доступом, а также с использованием современных технологий защиты данных, соответствующих требованиям безопасности.

6. Условия передачи персональных данных

Администрация Сайта обязуется не передавать персональные данные третьим лицам за исключением следующих случаев:

  • При наличии явного согласия Пользователя на передачу данных;
  • При необходимости передачи данных для выполнения обязательств перед Пользователем (например, для исполнения заказа или предоставления услуги);
  • По требованию законодательства, когда передача данных третьим лицам является обязательной;
  • Для защиты прав администрации сайта, если пользователь нарушает правила использования сайта.

Пользователи Сайта имеют право:

  • Отозвать согласие на обработку персональных данных в любой момент, направив соответствующее уведомление Администрации Сайта.

Сайт использует cookie, чтобы страницы работали корректно. Пользователь может отключить cookie в браузере, но часть функций сайта может работать хуже.
